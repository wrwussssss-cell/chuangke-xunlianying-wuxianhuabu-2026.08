# 创客训练营 · 无限画布 2026.08（内部版）

这是 AI 创客训练营使用的无限画布工具安全发布版。

## 使用前配置

1. 双击 `启动服务.bat` 启动服务。
2. 打开 API 设置页面。
3. 按文件夹中的《无限画布配置步骤（2026.10.02）》完成 API 注册和配置。
4. 将 `API/.env.example` 复制为 `API/.env`，只在本地填写自己的 Key。

本仓库不会保存真实 API Key、个人画布、历史记录或生成素材。

## 说明

- T8 API 配置完成后会自动拉取预设模型。
- VIP-GPT 等服务的额度、模型和可用性以对应平台为准。
- 请勿将 `API/.env` 提交到 GitHub，也不要把 API Key 发到公开渠道。
