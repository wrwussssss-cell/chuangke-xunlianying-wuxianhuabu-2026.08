# 创客训练营 · 无限画布 2026.08（外部版）

这是面向学员的无限画布外部发布版，提供节点式画布、图片生成、图生图、素材管理、工作流和多平台 API 配置功能。

## 下载与版本

- Windows 外部版：下载仓库代码后，在根目录运行 `启动服务.bat`。
- Mac 独立版：进入 [`mac/`](./mac/) 目录，适用于 Apple Silicon（M 系列）Mac。
- 历史更新：查看 [`CHANGELOG.md`](./CHANGELOG.md)。

## Windows 使用方法

1. 下载或克隆本仓库到本地。
2. 双击根目录的 `启动服务.bat`。
3. 浏览器打开 `http://127.0.0.1:3000`。
4. 首次使用先注册账号，以后使用用户名和密码登录。
5. 进入“API 设置”，按文件夹内的《无限画布配置步骤（2026.10.02）》注册并填写平台 Key。
6. 回到无限画布，新建节点并连接后即可开始生成。

## Mac 使用方法

1. 进入 [`mac/`](./mac/) 文件夹。
2. 首次运行前双击 `mac-修复权限.command`。
3. 双击 `mac-启动服务.command` 启动服务。
4. 浏览器打开终端提示的本地地址，首次使用先注册账号。
5. 在“API 设置”中填写自己的 Key，再开始生成。

Mac 版本自带独立 Python 运行环境，当前主要面向 Apple Silicon（M 系列）Mac，Intel Mac 兼容性待确认。

## 账号与隐私

- 账号、密码摘要和个人画布保存在本机 `data/` 目录中。
- 不同账号的画布列表和新建内容互相隔离。
- 不要在公共电脑上保存密码，也不要把账号文件复制给别人。

## API 配置说明

- API Key 只填写在本地 `API/.env` 或网页 API 设置页面中。
- `API/.env.example` 仅是配置模板，不包含真实 Key。
- T8 API 配置完成后会自动拉取预设模型。
- VIP-GPT、T8、ModelScope、RunningHub、AutoDL 等服务的额度和可用性以对应平台为准。
- 不要将真实 API Key、个人画布、历史记录或生成素材上传到 GitHub。

## 已知限制

- 在线生成需要有效的 API Key、网络连接和对应平台额度。
- Mac 版尚未在 Intel Mac 上完成完整验证。
- 上游平台可能出现限流、Cloudflare 拦截或模型下线。
