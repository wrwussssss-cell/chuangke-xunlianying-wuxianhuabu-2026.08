创客训练营｜无限画布 2026.08 内部版
运行与 API 配置说明

一、启动程序

1. 双击“启动服务.bat”。
2. 等待浏览器自动打开无限画布页面。
3. 如果浏览器没有自动打开，请手动访问窗口中显示的本地地址。
4. 第一次使用前，建议先打开 API 设置页面，阅读顶部的“获取 api 的教程”，并查看文件夹内的《无限画布配置步骤（2026.10.02）》PDF。

二、本版本配备的 3 个主要 API 入口

左侧 API 设置中的前 3 个入口是本版本主要配备的平台：

1. T8 API
   - 适合使用 Seedance 相关图像模型。
   - 点击“获取 Key”注册并获取自己的 API Key。
   - 填写并保存 Key 后，系统会自动配置：
     · G2 Image Lowprice
     · G2.5 Image Lowprice
   - 不需要手动拉取或选择模型。

2. RunningHub
   - 支持图像、视频、工作流等功能。
   - 点击“获取 Key”进入注册页面并申请自己的 Key。
   - 使用 RunningHub 工作流时，需要先在 API 设置中保存 Key，再打开对应工作流。

3. AutoDL
   - 用于 GPU 云平台、模型部署和相关 AI 工作负载。
   - 点击“获取 Key”或对应入口进入 AutoDL 注册页面。
   - AutoDL 主要用于 GPU 和模型运行环境，不是普通的 OpenAI 生图接口。

三、VIP-GPT 已有 Key 的使用方法

本内部版已经预先配置 VIP-GPT API Key，学员不需要重新填写。

使用步骤：

1. 打开“无限画布”。
2. 新建一个生图节点，或打开已有的生图节点。
3. 在平台/提供商中选择“VIP-GPT”。
4. 选择可用的图像模型。
5. 输入提示词后点击生成。

当前 VIP-GPT Key 预计可以生成约 200 张 1K 分辨率图片，实际数量会受到平台计费、模型价格和图片尺寸影响。请优先使用 1K 分辨率，避免随意切换更高分辨率或高价模型。

注意：
- 不要删除 VIP-GPT 配置。
- 不要把 Key 复制到其他软件或公开群聊中。
- 如果出现额度不足、Key 失效或接口报错，请联系课程提供者，不要重复提交大量任务。

四、推荐使用顺序

1. 第一次体验：优先使用 VIP-GPT 生成 1K 图片。
2. 需要 Seedance 模型：注册并配置 T8 API。
3. 需要 RunningHub 工作流：注册并配置 RunningHub。
4. 需要 GPU、部署模型或运行本地环境：使用 AutoDL。

五、基础排错

- 保存 Key 后没有模型：刷新页面，确认平台地址和 Key 没有多余空格，然后重新保存。
- VIP-GPT 无法生成：确认平台选择的是 VIP-GPT，并将分辨率设置为 1K。
- T8 无法生成：确认已经保存 T8 Key，并等待模型自动配置完成。
- RunningHub 工作流报错：确认 RunningHub Key 有效，并先在 API 设置中同步工作流参数。
- 页面打不开：关闭正在运行的服务窗口后，重新双击“启动服务.bat”。

本版本只保证前面 3 个主要 API 入口的配置指引；其他平台仅作为界面预留或扩展选项，学员可根据需要自行注册和配置。
