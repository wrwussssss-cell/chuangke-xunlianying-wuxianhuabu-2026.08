## 一分钟速览

- **架构**：单文件 FastAPI 后端（`main.py`，1.89 万行）+ 无构建原生 JS 前端（`static/`，最大的两个文件 `smart-canvas.js` 1.78 万行、`canvas.js` 1.49 万行）。
- **双画布**：`canvas.html`（无限画布，自由节点）与 `smart-canvas.html`（智能画布，批量/级联流水线）。
- **渠道**：OpenAI 兼容 API（含 APIMart 异步）、ModelScope、本地 ComfyUI（多实例）、RunningHub、火山引擎、即梦 CLI、Codex/Gemini CLI、Angle——统一调度在 `generate_ai_image`（main.py:11005）与 `canvas_video`（main.py:15046）。
- **数据**：全部本地文件（`data/` JSON + `assets/` 媒体 + 根目录 `history.json`），Key 在 `API/.env`。
- **启动**：`启动服务.bat` → `http://127.0.0.1:3000/`。
