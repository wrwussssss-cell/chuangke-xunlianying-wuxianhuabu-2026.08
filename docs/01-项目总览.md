# Infinite Canvas（无限画布）项目总览

> 文档版本：2026-09-06 ｜ 对应项目版本：2026.07.28.1（见根目录 `VERSION`）
> 本文档面向二次开发者，目标是让人快速理解"这个工具是什么、怎么跑起来、代码在哪里"。

---

## 1. 项目定位

**Infinite Canvas（无限画布）** 是一个**本地运行的 AI 图像/视频/文本生成工作台**。它本质上是：

```
一个 FastAPI 单文件后端（main.py） + 一个纯原生 HTML/JS 前端（static/）
```

- 程序跑在用户自己电脑上，浏览器访问 `http://127.0.0.1:3000/`，局域网内其他设备也能通过 `http://<局域网IP>:3000/` 访问。
- **不绑定任何单一平台**：可以接 OpenAI 兼容 API（APIMart 等）、ModelScope（魔搭，免费）、本地 ComfyUI、RunningHub 云端工作流、火山引擎（豆包/Seedream/Seedance）、即梦 CLI（Jimeng）、Codex CLI、Gemini CLI 等多种渠道生成图片/视频，或调用大语言模型聊天。
- 用户数据（画布、素材库、历史记录、对话）全部保存在本地 JSON 文件和目录中，不依赖数据库。

核心能力一览：

| 能力 | 说明 |
|---|---|
| 无限画布（classic） | 自由拖拽缩放的节点式画布，图片/视频/文本/LLM/分组/循环等节点，连线传递图片与提示词 |
| 智能画布（smart） | 面向"批量+级联生成"的另一种画布形态，支持智能分组、循环批量、级联运行 |
| 多渠道生图 | API（OpenAI/Gemini/Grok 等协议）、ModelScope、ComfyUI 工作流、RunningHub、火山引擎、即梦、Codex/Gemini CLI |
| 多渠道生视频 | APIMart（含 Veo3.1）、Agnes、Yuli、灵境、Grok、土豆(Seedance)、火山引擎、RunningHub、即梦 CLI |
| LLM 聊天 | 独立聊天页 + 智能体模式（自动判断画图还是回答文本，可流式输出） |
| 素材库 | 本地素材上传/分类/AI 自动打标/裁剪/数字人资产注册 + URL 公网库 + 提示词库 |
| 工作流生态 | 内置 ComfyUI 工作流 JSON + 自定义导入导出 + RunningHub 工作流托管 |
| 生态插件 | Chrome 网页图片采集插件、Photoshop UXP 资产面板（双向同步） |
| 自更新 | 从 GitHub / ModelScope 拉取更新、备份、回滚 |

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3 + FastAPI + uvicorn（**单文件 main.py，约 18900 行**），httpx / requests 上游调用，Pillow 图像处理 |
| 前端 | 原生 JavaScript（无框架、无构建），TailwindCSS 本地镜像 + lucide 图标 + three.js（`static/vendor/`），i18n 中英双语（`i18n-core.js`） |
| 通信 | HTTP REST + SSE 流式（聊天）+ WebSocket（`/ws/stats` 状态广播、PS 插件实时同步） |
| 存储 | 纯文件：JSON（配置/画布/对话/素材索引）+ 原始媒体文件目录 |
| 运行时 | 内嵌 Python（`python/` 目录），Windows 下 `启动服务.bat` 一键运行；也有 macOS 启动脚本 |

---

## 3. 如何运行（开发视角）

1. `启动服务.bat`：优先用 `python\python.exe main.py`（内嵌运行时），否则回退系统 `python`。启动前用 PowerShell 探测局域网 IP，打印访问地址并延时打开浏览器。
2. 服务监听 **3000 端口**，根路径 `/` 由 `main.py` 提供。
3. macOS：`mac-启动服务.command`、`mac-修复权限.command`（详见 `MAC-使用说明.md`）。
4. 依赖安装：`安装依赖.bat`（优先离线 `packages/`，失败则联网 pip）。核心依赖：fastapi、uvicorn、httpx、requests、Pillow。

> 二次开发建议：直接 `python main.py` 跑起来，改完前端刷新浏览器即可；改 `main.py` 需要重启服务。

## 5. 前端页面清单（路由与职责）

| `canvas.html` | 无限画布 | 节点式无限画布（核心） | `js/canvas.js` |
| `smart-canvas.html` | （无标题） | 智能画布：批量/级联生成 | `js/smart-canvas.js` |

| `canvas-list.html` | 项目工作台 | 项目/画布列表、回收站 | `js/canvas-list.js` |
| `asset-manager.html` | 素材库管理 | 素材库/URL 库/提示词库管理 | `js/asset-manager.js` |
| `api-settings.html` | API 设置 | 渠道增删改、协议、验证、拉模型 | `js/api-settings.js` |
| `comfyui-settings.html` | 工作流设置 | ComfyUI 实例管理、工作流导入与参数配置 | `js/comfyui-settings.js` |
| `online.html` | 在线生图 | 快捷单图生成页 | 内联 |
| `zimage.html` | Flux Modern Gallery | Flux 统一控制台 | 内联 |

## 6. 整体数据流（一次生成为例）

```
浏览器画布节点
   │ ① 用户点"生成"
   ▼
前端 canvas.js / smart-canvas.js
   │ ② POST /api/canvas-image-tasks（或 /api/generate、/api/ms/generate、/api/canvas-video ...）
   ▼
main.py 生成管线
   │ ③ 按 provider id 找到渠道配置（data/api_providers.json + API/.env 中的 Key）
   │ ④ 组装上游请求（OpenAI 兼容 / Gemini / 火山 V4 签名 / ComfyUI prompt / RunningHub webapp / 即梦 CLI 子进程）
   │ ⑤ 提交任务 → 轮询等待（wait_for_image_task / wait_for_video_task ...）→ 下载产物存入 output/
   ▼
历史记录 history.json  ←  save_to_history()（main.py:3098）
   │
前端
   │ ⑥ 轮询 /api/canvas-image-tasks/{task_id} 或直接拿到结果 URL
   ▼
画布新建 output 节点展示结果，画布 JSON 自动保存到 data/canvases/{id}.json
```
