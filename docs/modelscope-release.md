# 魔塔发布规则

- 发布目标是 ModelScope Studio 的 `master` 分支。每次发布前提高 `VERSION`，并为该版本更新 `static/update-notes.json`，让客户端能识别新版本。
- 从可部署的源码发布。个人画布、历史、素材、输出、账号数据、`API/.env` 和桌面随包的 Python 运行环境留在本地。
- 用户已明确批准公开的训练营共享 Key 单独放在魔塔仓库的 `static/training-camp-kie-key.txt`。每次发布保留该文件。换 Key 时，只在魔塔的发布分支替换此文件，其他凭据继续保存在各自本地配置里。
- 该文件会随更新下载，领取者也可以读取这枚共享 Key。公开额度与使用限制由 Kie.ai 管理。画布项目里，这个端口的分辨率固定为 1K。
- 如果以后通过 GitHub Actions 同步代码到魔塔，流程必须从魔塔上一版继承公开 Key 文件。GitHub 源码、日志和发布说明不写 Key 的值。
- 外部版从 GitHub 更新时，从官方魔塔空间补齐共享 Key，并在临时网络异常时保留已有配置。公开 Key 仍由魔塔分发。
- 发布后核对远端提交、`VERSION`、更新说明和训练营端口，并确认使用旧版本的用户能从版本号入口找到更新。
