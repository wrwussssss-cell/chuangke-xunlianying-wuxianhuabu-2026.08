# 数据结构与存储

> 所有持久化都是**本地文件**，无数据库。改任何 schema 时注意：后端有归一化函数（`normalize_*`）做兼容，旧文件缺字段会被自动补默认值——新增字段建议沿用这个模式。

---

## 1. 画布：`data/canvases/{id}.json`

实测字段（`new_canvas` main.py:3268 / `canvas_record` main.py:3316）：

```json
{
  "id": "39f8296bcd9d4269a9bb10348886097a",
  "title": "未命名画布",
  "icon": "layers",            // lucide 图标名（CANVAS_EMOJIS canvas.js:530）
  "kind": "classic",           // classic=无限画布 | smart=智能画布（normalize_canvas_kind main.py:3201）
  "owner": "",
  "color": "slate",            // CANVAS_COLOR_OPTIONS canvas.js:414
  "pinned": false,
  "project": "default",        // 所属项目 id
  "created_at": 0, "updated_at": 0,   // 毫秒时间戳
  "nodes": [ /* 见下 */ ],
  "connections": [ { "id": "...", "from": "节点id", "to": "节点id" } ],
  "viewport": { "x": 0, "y": 0, "scale": 1 },
  "board_x": null, "board_y": null,   // 在项目板上的位置
  "deleted_node_ids": [],      // 软删除节点（撤销用）
  "logs": [],                  // 画布内生成日志（可单独删除 /logs/delete）
  "settings": {}               // 画布级设置
}
```

节点字段按类型扩展（公共：`id, type, x, y, name`）：

- 图片类：`url, mediaKind('image'|'video'|'audio'|'text'), natural_w, natural_h`
- 生成器类：`provider/provider_id, model, ratio, resolution, quality, count, params…`（与后端 `/api/image-params` 返回的字段对应）
- `prompt`：`text`（上限 20000，`PROMPT_TEXT_MAX_LENGTH` canvas.js:522）
- 运行态字段（`_naturalSizeLoading` 等）以下划线开头，保存时应剔除（智能画布 `serializableSmartNode` smart-canvas.js:800）。

**回收站**：删除=打 deleted 标记，30 天后 `cleanup_expired_canvas_trash`（main.py:3334）清理；`/purge` 立即彻底删除。

## 2. 渠道配置：`data/api_providers.json`（数组）

```json
[
  {
    "id": "comfly",              // 稳定 id；Key 存 API/.env 的 API_PROVIDER_COMFLY_KEY
    "name": "APIMart",
    "base_url": "https://api.apimart.ai",
    "protocol": "openai",        // openai | openai-responses | gemini | volcengine | jimeng | runninghub | codex | gemini-cli ...
    "image_request_mode": "openai",   // openai(同步) | async(异步任务)
    "image_generation_endpoint": "",  // 可覆盖默认端点
    "image_edit_endpoint": "",
    "enabled": true,
    "primary": true,
    "image_models": ["gpt-image-1", "..."],
    "chat_models": ["..."],
    "video_models": ["..."],
    "model_names": {},           // 模型显示名映射
    "model_protocols": {},       // 按模型覆盖协议
    "ms_loras": [],              // ModelScope LoRA 列表
    "ms_defaults_version": 0,
    "rh_apps": [],               // RunningHub webapp 条目
    "rh_workflows": [],          // RunningHub 工作流条目
    "volcengine_project_name": "", "volcengine_region": ""
  }
]
```

读写：`load_api_providers`/`save_api_providers`（main.py:1294/1307）；默认项合并 `merge_default_api_providers`（main.py:841）；RunningHub 有系统静态配置合并（`static/runninghub/api_providers.json`，main.py:1111–1145）。

**Key 存储**：`API/.env`，规则 `API_PROVIDER_<大写ID>_KEY`；另有 `MODELSCOPE_CHAT_MODELS`、火山 `AK/SK`、RunningHub 钱包 Key 专用名（main.py:702–757）。写入统一走 `update_env_values`（main.py:1411）。

## 3. 历史记录：`history.json`（根目录，数组）

```json
[
  {
    "prompt": "...",
    "images": ["output/xxx.png"],        // 兼容旧字段
    "image_items": [ { "url": "...", "model": "..." } ],
    "timestamp": 0,
    "type": "image",                     // image | video | chat ...（/api/history?type= 过滤）
    "model": "...", "provider_id": "...", "provider_name": "...",
    "task_id": "...", "request_id": "...",
    "params": {},                        // 当次请求参数快照
    "raw_usage": {}                      // 上游用量/计费信息（若有）
  }
]
```

写入：`save_to_history`（main.py:3098）。删除媒体文件时会联动清理引用它的历史（`prune_generation_history_for_media` main.py:6526）。

## 4. 素材库：`data/asset_library.json`

```json
{
  "active_library_id": "...",
  "libraries":  [ { "id": "...", "name": "默认素材库", ... } ],
  "categories": [ { "id": "...", "name": "...", "library_id": "...", "items": [...] } ],
  "updated_at": 0
}
```

- 素材条目（`make_asset_library_item` main.py:7155）：`id, name, path/url, kind(image|video|audio|workflow), category_id, source, created_at, caption(打标文本), classification(AI 分类标签), avatar(数字人资产信息)…`
- 实体文件在 `assets/library/<分类目录>/`；多库迁移 `migrate_asset_library_into_dirs`（main.py:7367）。
- 归一化：`normalize_asset_library`（main.py:7017）。
- URL 公网库：独立结构（`normalize_asset_url_library` main.py:7473，条目含 `id/url/kind/name…`），接口 `/api/asset-url-library*`。
- 提示词库：`normalize_prompt_libraries`（main.py:7792），首次启动播种 `static/system-prompts/infinite-canvas-prompt-templates.md`（`seed_system_prompt_library` main.py:7740）。

## 5. 会话：`data/conversations/{user_id}/{conversation_id}.json`

`new_conversation`（main.py:3148）：`{ id, user_id, title, created_at, updated_at, messages: [{ role, content, images(引用), attachments… }] }`。列表接口返回摘要（`list_conversations` main.py:3167）。

## 6. ComfyUI 相关

- 实例列表：`/api/comfyui/instances` 存储的 JSON（`ComfyInstancesPayload` main.py:18725），多实例负载选择 `get_best_backend`（main.py:2896）。
- 工作流：`workflows/*.json`（ComfyUI API 格式，顶层是节点 id → `{class_type, inputs}`）。内置：

| 文件 | 用途 | 关键注入点（main.py:18113 起） |
|---|---|---|
| `Z-Image.json` | 文生图主力 | 节点23=提示词，144=宽高，22/158/146/181/184/172/14=种子 |
| `Z-Image-Enhance.json` | 图生图增强 | 同上规则 |
| `upscale.json` | 放大 | enhance 页调用 |
| `LTXDirectorv2-API.json` + `.config.json` | LTX 视频导演（分段视频） | 前端常量 `LTX_DIRECTOR_WF_NODE='46'`、`LTX_DIRECTOR_SEED_NODE='94:28'`（canvas.js:526–528）；config 定义可调字段 |
| `Flux2-Klein.json` | Flux Klein 页 | 同名页面使用 |
| `2511.json` | 备用/示例工作流 | — |

- 参数配置：`{workflow}.config.json`（`WorkflowConfig` main.py:18288），声明哪些字段暴露给用户（类型/默认值/选项），保存于同目录。
- RunningHub 工作流 store：与 provider 配置同步（`sync_runninghub_workflow_to_provider` main.py:18519），字段提取 `runninghub_collect_workflow_fields`（main.py:18683）。
