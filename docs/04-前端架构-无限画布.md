## 3. 坐标与渲染

- **坐标变换**：`screenToWorld(clientX, clientY)`（canvas.js:1196），世界坐标 = 屏幕坐标经 viewport 逆变换。
- **渲染方式**：**DOM 节点 + SVG 连线**。每个节点是一个 DOM 元素（`renderNode` canvas.js:6090），连线用 `document.createElementNS('http://www.w3.org/2000/svg', 'polyline'/'path')`（canvas.js:14380/14462）。
- **高清图懒加载**：缩略图走 `/api/media-preview`（webp），当 `viewport.scale > 0.86`（`CANVAS_HIGH_RES_ZOOM_THRESHOLD` canvas.js:133）时对视口内选中/可见图换原图（`syncCanvasSelectedImageResolution` canvas.js:172、`canvasImageNearViewport` canvas.js:162）。
- **视口记忆**：每个画布的视口存 localStorage `canvas_session_viewports_v1`（canvas.js:557，`loadLocalViewportMap` canvas.js:584）。

## 6. 生成流程（canvas.js:11724 起）

主入口 `runCanvasGenerate(nodeId)`（canvas.js:11724）：

1. 从生成器节点读配置（provider/model/size/refs），上游图片来自连线簇（`generatedImageRefs` canvas.js:10284）。
2. 按生成器类型分流：
   - **API 渠道**：`createCanvasImageTask`（canvas.js:12371）→ `POST /api/canvas-image-tasks` → `pollCanvasImageTask`（canvas.js:12486）轮询 `GET /api/canvas-image-tasks/{id}` → 结果 URL 建 `output` 节点。
   - **ComfyUI**：`createCanvasComfyTask`（canvas.js:12380）→ `runQueuedComfyGenerate`（canvas.js:12405，先看 `/api/queue_status`/ws 排队）→ `waitCanvasComfyTaskResult`（canvas.js:12389）。
   - 其他渠道（MS/RH/即梦）各自调用 `/api/ms/generate`、`/api/runninghub/*`、`/api/canvas-video` 等（见接口清单）。
3. 视频走 `/api/canvas-video`（参考图先经 `/api/ai/upload` 或公网化）。

**渠道/模型解析辅助**：`imageApiProviders`（683）、`providerById`（688）、`resolveImageProviderId`（711）、`providerImageModels`（721）、`videoProviderOptions`（742）、`modelscopeImageModels`（775，内置 `MS_GEN_MODELS` canvas.js:440）、`DEFAULT_VIDEO_MODELS`（canvas.js:560）、即梦 Seedance 模型表（canvas.js:581）。

**尺寸规则**：`SIZE_MAP`（比例→像素，canvas.js:539）、`RES_LONG_SIDE/RES_PIXEL_LIMIT`（1k/2k/4k 上限，canvas.js:550）、`apiImageSize`（canvas.js:999）。

**提示词模板**：模板库来自后端（`/api/smart-canvas/prompt-templates` 与 prompt-libraries），分组/覆盖存 localStorage（canvas.js:470–477），另存为模板 `saveCurrentCanvasPromptAsTemplate`（canvas.js:7350）。

## 7. 配置热刷新

设置页改了渠道/工作流/ComfyUI 实例后，会通过 localStorage 事件广播（`CANVAS_API_CONFIG_EVENT_TYPES` canvas.js:226），画布页 `refreshCanvasConfigFromSettings`（canvas.js:252）延迟拉取新配置，无需刷新页面。
