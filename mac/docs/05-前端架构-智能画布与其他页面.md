## 1. 智能画布（smart-canvas.html + smart-canvas.js）

> `static/js/smart-canvas.js` **17836 行**，是全项目最大的前端文件。
> 与无限画布的区别：无限画布是"自由节点工作台"，智能画布面向**批量生产流水线**——围绕"提示词节点 → 生成节点"的组合，支持**循环批量（smart-loop）**、**级联（cascade，A 的输出作为 B 的输入逐轮推进）**、**智能分组（smart-group）** 与一键分组导出。

### 1.1 全局状态（smart-canvas.js:73–311）

```js
let nodes = [];                 // 所有节点（73）
let selectedId = '' / let selectedIds = [];   // 单选/多选（74/75）
let selectedImage = {nodeId:'', index:-1};    // 节点内选中图片（76）
let viewport = {x:0, y:0, scale:1};           // 视口（310）
let settings = { ... };         // ★ 全局生成设置面板（311，字段见下）
let smartCascadeRuns = new Map();             // 级联运行实例（级联可并发多个 loop）
```

`settings` 关键字段（smart-canvas.js:311–368）：

- 通用：`engine`（api/msgen/comfy/rh/jimeng…）、`apiKind`、`provider_id`、`model`、`ratio`、`resolution`、`quality`、`count`、自定义比例/尺寸字段。
- 视频：`videoProvider/videoModel/videoDuration/videoAspect/videoResolution/videoEnhancePrompt/videoEnableUpsample/videoWatermark/videoCameraFixed/videoGenerateAudio/videoMultimodal/videoUseFrameRoles/videoTrustedAsset/videoTempShLinks`。
- ModelScope：`msgenModel/msCustomModel/msRatio/msResolution/msCustom*`。
- ComfyUI：`comfyMode('text'/…)`、`comfyWorkflow`、`comfyParams`。
- RunningHub：`rhConfigKey/rhPayment('free'/…)/rhInstanceType/rhParams/rhRandomActive`（字段随机化开关）。
- 增强：`enhanceStrength/enhanceUpscale/enhanceUpscaleRes/editUpscale/editUpscaleRes/jimengUpscaleRes`。

### 1.2 节点类型（5 种）

| type | 含义 |
|---|---|
| `smart-prompt` | 提示词节点（生成源头） |
| `smart-image` | 图片节点 |
| `smart-loop` | 循环节点：一轮生成 N 张/逐轮输出，配 `runLoopRoundIntoSlot`（smart-canvas.js:14772） |
| `smart-group` | 分组：可整体导出（`/api/smart-canvas/group-export`） |
| `smart-container` | 容器节点 |

### 1.3 级联引擎（这是智能画布的心脏）

- `runSmartCascade(targetNode)`（smart-canvas.js:14952）：主入口，从某节点出发沿连线推进。
- `runCascadeStepIntoNode(sourceNode, targetNode, inputRefs, ctx)`（smart-canvas.js:14669）：单步——把上游输出作为下游输入再生成。
- `runLoopRoundIntoSlot`（14772）：循环节点的一轮执行。
- `runSmartCascadeRoundsWithLimit`（14934）：限轮次执行。
- 运行状态管理：`smartCascadeRunForLoop / smartCascadeIsLoopRunning / smartCascadeEdgeState`（smart-canvas.js:171–184），支持多 loop 并发、单步暂停与边状态高亮。
- 撤销：`snapshotForUndo / pushUndo / performUndo`（smart-canvas.js:203–218，上限 `UNDO_LIMIT=40`）。

### 1.4 生成调用

- `generateUrlsForCurrentSettings(node, prompt, refs, runSettings)`（smart-canvas.js:14571）：按 settings 组装请求；`generateComfyUrlsWithSettings`（14606）走 ComfyUI；`runQueuedSmartComfyGenerate`（14538）排队。
- 任务轮询与无限画布相同：`/api/canvas-image-tasks`、`/api/image-task-query`、`/api/canvas-video`、`/api/ms/generate`、`/api/runninghub/*`、`/api/angle/generate`、`/api/jimeng/query-media`。
- 素材直连：本地素材 `/api/local-assets*`、素材库 `/api/asset-library/*`、URL 库 `/api/asset-url-library/*`。

### 1.5 工作流传输

画布可整体导出/导入为 JSON（含资源包）：`exportSelectedSmartWorkflow`（smart-canvas.js:853）、`normalizeImportedSmartWorkflow`（826）、下载 `downloadBlob`（768）。存储时剔除临时运行态：`serializableSmartNode`（800）、`mediaItemForStorage`（712）、`canvasForStorage`（722）。

### 1.6 其他要点

- 提示词预设/模板：`PROMPT_PRESETS_KEY` 等三个 localStorage 键（smart-canvas.js:117–119）+ 后端模板接口。
- 配置 30 秒焦点刷新：`SMART_CONFIG_FOCUS_REFRESH_MS`（138）。
- 全景图比例预设 `PANORAMA_RATIO_PRESETS`（276，配合 angle/360 功能）。
- 视口应用 `applyViewport`（2069）。
- 高清图策略与无限画布一致（`SMART_HIGH_RES_ZOOM_THRESHOLD` 564）。

## 2. 聊天页（gpt-chat.html，1645 行，JS 内联）

- 接口：`POST /api/chat`、`/api/chat/stream`（SSE）、`/api/chat/agent`、`/api/chat/agent/stream`（智能体 SSE）、会话 CRUD `/api/conversations*`、参考图 `/api/ai/upload`、配置 `/api/config`。
- 智能体模式：后端 `decide_chat_agent_action`（main.py:11414）先决策（文本回答 / 生图 / 多路并行生图），前端按 SSE 事件类型渲染（文本增量、图片卡片、进度）。
- 附件：图片（多模态）与 xlsx/文本（后端 `read_xlsx_attachment` main.py:8118 解析成文本块）。
- 会话按 `X-User-Id` 头隔离（默认单用户 anonymous）。
