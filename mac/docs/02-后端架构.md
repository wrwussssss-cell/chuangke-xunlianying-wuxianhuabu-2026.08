## 2. 启动流程与全局对象

- `app = FastAPI()`（main.py:69）；CORS 全开放（main.py:71）。
- `@app.on_event("startup")` → `startup_event()`（main.py:181）：初始化运行时配置文件（`ensure_runtime_config_files` main.py:510）、加载 `.env`、静态 HTML 版本号同步（`sync_static_html_versions` main.py:1592，给页面 URL 加 `?v=` 破缓存）、回收站清理等。
- 全局可变状态（进程内单例）：
  - `NEXT_TASK_ID` / `QUEUE` / `QUEUE_LOCK`：ComfyUI 任务队列（main.py:18051 附近使用）。
  - `COMFYUI_INSTANCES`：ComfyUI 实例列表（持久化见 `/api/comfyui/instances` main.py:18728）。
  - WebSocket 连接表 `ConnectionManager`（main.py:79），`/ws/stats`（main.py:201）按 `client_id` 推送队列状态，前端用 `CLIENT_ID = canvas_…`（canvas.js:523）订阅。
- 目录常量：assets、output、data、workflows 等由 `apply_storage_settings`（main.py:291）统一管理，用户可在"存储设置"里改（`/api/storage-settings` main.py:6698）。

## 3. API Provider 配置体系（渠道系统的核心）

**三层结构：**

1. `data/api_providers.json`：用户渠道列表（数组），每项字段：
   `id, name, base_url, protocol, image_request_mode, image_generation_endpoint, image_edit_endpoint, enabled, primary, image_models, chat_models, video_models, model_names, model_protocols, ms_loras, ms_defaults_version, rh_apps, rh_workflows, volcengine_project_name, volcengine_region`
2. `API/.env`：Key 存储，命名规则 `API_PROVIDER_<大写ID>_KEY=...`（读写函数 `provider_key_env` main.py:702、`update_env_values` main.py:1411）。ModelScope/Volcengine/RH钱包各有专用 env 名（main.py:713–757）。
3. `static/runninghub/api_providers.json`：**系统内置 RunningHub 配置**（随版本分发的静态覆盖层），加载时与用户配置合并（`load_static_runninghub_provider` main.py:1111、`merge_runninghub_provider_with_static` main.py:1130），应用内置工作流缩略图（main.py:1061）。

关键函数：

| 函数 | 行号 | 作用 |
|---|---|---|
| `default_api_providers` | 784 | 内置默认渠道列表 |
| `merge_default_api_providers` | 841 | 用户配置合并缺失的默认项 |
| `normalize_provider` | 1239 | 字段归一化 |
| `load_api_providers / save_api_providers` | 1294/1307 | JSON 读写 |
| `public_api_providers` | 1348 | 返回给前端（Key 脱敏 `mask_secret` main.py:767） |
| `get_api_provider` | 1362 | 按 id 取渠道（含默认回退） |
| `provider_protocol / effective_protocol` | 4288/4318 | 渠道协议判定：openai / openai-responses / gemini / volcengine / jimeng / runninghub / codex / gemini-cli…（支持按模型覆盖 `model_protocols`） |
| `is_*_provider` 系列 | 4331–4382 | apimart / fhl / gemini / grok / volcengine / runninghub / jimeng / codex / gemini-cli / yuli / lingjing / agnes 判定 |
| `update_env_values` | 1411 | 把 Key 写回 `API/.env` |

**验证与拉模型**：`test_provider_connection`（main.py:13307）按协议探测上游（OpenAI `/models`、火山自动探测 main.py:13236 等）；异步生图渠道额外有 `probe_async_endpoint`（main.py:13420）；`fetch_models_from_upstream`（main.py:13565）拉取模型列表并按 `classify_upstream_model`（main.py:13257）分类到 image/chat/video。

## 4. 生成管线（图片）

**统一调度器：`generate_ai_image(prompt, size, quality, model, reference_images, provider_id, aspect_ratio, resolution)`（main.py:11005）**

流程：取 provider → 按 `effective_protocol` 分发：

| 渠道 | 实现函数（行号） | 说明 |
|---|---|---|
| OpenAI 兼容（APIMart 等） | 内联在 generate_ai_image | 同步（`/images/generations` 或 chat 多模态）与异步两种 `image_request_mode`；异步提交后 `wait_for_image_task`（main.py:6318）轮询 `/api/image-task-query` 的同一逻辑；Responses 协议走 `post_openai_responses`（main.py:4114） |
| ModelScope | `generate_modelscope_provider_image`（9698） | 免费渠道，支持 LoRA（`ms_loras`） |
| Gemini 协议 | `generate_gemini_provider_image`（9791） | `:generateContent` + reference 内联 |
| Grok | `generate_grok_image`（14682） | 图生图 multipart |
| 火山引擎 | `generate_volcengine_provider_image`（9821） | V4 签名，Seedream 尺寸规则（`normalize_volcengine_size` 9548） |
| RunningHub | `generate_runninghub_provider_image`（10852） | 两类：注册表模型（OpenAPI，`wait_for_runninghub_openapi_task` 10906）和 webapp 工作流（`generate_runninghub_entry_image` 10745） |
| 即梦 CLI | `generate_jimeng_provider_image`（6049） | 子进程调用 CLI，排队抛 `JimengPendingError`（专用异常处理器 main.py:5695 返回"排队中"载荷） |
| Codex CLI | `generate_codex_provider_image`（4946）/ gpt_image_2_skill（4774） | 本地 CLI 生图 |
| Gemini CLI | `generate_gemini_cli_provider_image`（5196） | 本地 CLI 生图 |
| Angle（云端） | `generate_angle_cloud`（17760，路由 `/api/angle/generate`） | 视角重塑专用渠道 |

**异步任务模式（画布用）**：前端 `POST /api/canvas-image-tasks`（main.py:13960）→ 后台线程 `run_canvas_image_task`（main.py:13919）→ 前端轮询 `GET /api/canvas-image-tasks/{task_id}`（main.py:13978）。ComfyUI 同理（`/api/canvas-comfy-tasks` main.py:14013）。

**图片参数 UI**：`/api/image-params`（main.py:14092）→ `build_image_param_fields`（main.py:14054）按 渠道+模型 动态返回参数表单定义（前端据此渲染设置面板）。

## 6. ComfyUI 执行与工作流参数注入

`generate(req: GenerateRequest)`（main.py:18049，路由 `POST /generate` 和 `/api/workflows/{name}/run`）：

1. 入队（`QUEUE`/`QUEUE_LOCK`），前端通过 `/ws/stats` + `/api/queue_status`（main.py:17637）看排队。
2. **多实例调度**：`collect_required_comfy_media`（main.py:2886）找需要的输入图 → `reserve_best_backend`（main.py:2926）选实例；若输入图不在目标实例，会从其他实例 `/view` 拉取并 `/upload/image` 同步过去（实例间输入同步，main.py:18066–18098）。
3. **参数注入**：读 `workflows/{workflow_json}`，然后按**节点 ID 硬编码注入**：
   - `"23".inputs.text` = 提示词
   - `"144"` = 宽高
   - 种子节点：`22, 158(noise_seed), 146, 181, 184, 172, 14`（main.py:18113–18125）
4. 提交 `/prompt` → 监听 → `download_comfy_output`（main.py:3015）下载产物到 `output/`，文本类输出 `save_comfy_text_output`（main.py:3033）。
5. 工作流管理路由：`/api/workflows` CRUD + run（main.py:18768–18866）；`WorkflowConfig`（main.py:18288）允许把工作流的可调字段抽成配置（`runninghub_collect_workflow_fields` main.py:18683 同样用于 RunningHub）。

## 7. LLM 聊天与智能体

- `/api/chat`（main.py:17084）非流式；`/api/chat/stream`（main.py:17465）**SSE 流式**（`sse_event` main.py:3683）；`/api/chat/agent`（main.py:17214）与 `/api/chat/agent/stream`（main.py:17299）为**智能体模式**：`decide_chat_agent_action`（main.py:11414）先让 LLM 输出 JSON 决策（画图/回答/继续追问，启发式兜底 `heuristic_agent_decision` main.py:11380），再分别执行生图（可多路并行 `chat_split_parallel_prompts` main.py:11345）或文本。
- 画布内 LLM 节点走 `/api/canvas-llm`（main.py:15542，`CanvasLLMRequest`）。
- 会话持久化：`data/conversations/`，按 `X-User-Id` 头区分用户目录（`safe_user_id` main.py:3119、`conversation_path` main.py:3133）。
- 附件：聊天支持 xlsx/文本附件（`read_xlsx_attachment` main.py:8118，纯 Python 解析）+ 图片附件。
- 视觉判断：`looks_like_vision_chat_model`（main.py:3614）、首选聊天模型 `preferred_chat_model`（main.py:3624）。

## 9. 素材库 / 提示词库 / URL 库 / 共享文件夹

- 素材库索引 `data/asset_library.json`（`load_asset_library` main.py:7076、归一化 `normalize_asset_library` main.py:7017），实体文件在 `assets/library/`。支持多库（libraries）/分类（categories）/条目（items），条目含媒体类型、路径、来源。
- **AI 自动打标**：`classify_image_with_provider`（main.py:7347）用视觉模型按"分类提示词"打标，提示词可自定义（`/api/asset-classification-prompt` main.py:6765）；本地上传即时打标缓存（main.py:7249–7335）。
- **数字人资产**：`register_avatar`（main.py:16708）把素材注册为 APIMart / 火山引擎的数字人资产（`submit_apimart_avatar_asset` main.py:8954、`submit_volcengine_avatar_asset` main.py:9106），轮询 `/api/asset-library/items/{id}/avatar-status`（main.py:16761）。
- 批量操作：删除/移动/裁剪（main.py:16813–16870，裁剪用 Pillow）。
- URL 公网库：`data` 中的 `asset_url_library`（`/api/asset-url-library` main.py:16122）。
- 提示词库：库/分类/条目 CRUD（main.py:16173–16350），首次启动从 `static/system-prompts/infinite-canvas-prompt-templates.md` 播种（`seed_system_prompt_library` main.py:7740，解析器 `parse_prompt_template_markdown` main.py:1703）；画布端还有 `/api/smart-canvas/prompt-templates`（main.py:15784）直接吐模板。
- 共享文件夹：注册本机任意目录为素材源（`/api/shared-folders` main.py:16489，扫描 `scan_shared_tree` main.py:7659、按需导入 main.py:16562）。

## 10. 画布 / 项目持久化

- 画布文件：`data/canvases/{id}.json`（结构见 06）。CRUD 路由集中在 main.py:15660–17080（创建/读取/meta/保存 `update_canvas` main.py:16926/删除/恢复/彻底删除，回收站 30 天过期清理 `cleanup_expired_canvas_trash` main.py:3334）。
- 项目（分组）：`/api/projects`（main.py:15663），默认项目 `ensure_default_project`（main.py:3233）。
- 画布资产收集：`extract_canvas_assets`（main.py:3439）遍历画布节点找出所有外部/临时媒体 URL，`/api/canvas-assets/download`（main.py:15807）批量落地到本地（画布搬家/防失效）。
- **画布工作流导出/导入**：把画布节点+连线+引用资源打包成 zip（`build_canvas_workflow_archive` main.py:15914），可导入恢复或存入素材库；智能画布分组导出 `/api/smart-canvas/group-export`（main.py:16070）。

## 11. 自更新机制

- 版本：`current_app_version`（main.py:1457，读 `VERSION`）。
- 检查：`/api/check-update`（main.py:1883）同时探测 GitHub Releases 与 ModelScope 源（`fetch_remote_version` main.py:1844，语义比较 `version_gt` main.py:1876）。
- 更新：`/api/update-from-github`（main.py:2197）按文件清单（`github_update_file_list` main.py:2134 / `modelscope_update_file_list` main.py:1993）下载到 staging（`stage_update_from_source` main.py:2188），校验后替换，备份到 update_backups（`/api/update-backups` main.py:2360），可回滚（`/api/update-rollback` main.py:2369），完成后 `schedule_self_restart`（main.py:2054）自杀重启。
- 连通性探测：`/api/update-connectivity`（main.py:1820）。
- 更新日志：`static/update-notes.json`（`read_local_update_notes` main.py:1511）。

## 13. 安全与健壮性要点（改动时注意）

- Key 永远不回传前端：`public_provider`（main.py:1313）+ `mask_secret`（main.py:767）。
