# 周边工具与生态

## 1. Chrome 插件：网页素材采集（`tools/chrome-local-asset-importer/`）

- 功能：扫描当前网页上可访问的图片，勾选后批量导入素材库的「本地素材」；可选"导入后智能分类"。
- 架构：MV3 扩展（`manifest.json` + `popup.html/js` + `sidepanel.html`），直接向主服务发 HTTP 请求。
- 使用：`chrome://extensions/` 开发者模式 → 加载已解压扩展 → 填服务地址（如 `127.0.0.1:3000`）→ 连接 → 扫描 → 导入。
- 后端落点：`POST /api/local-assets/upload`（main.py:12012）与 `/api/local-assets/classify`（main.py:12293）。
- 改动点：抓图逻辑在 `popup.js`/sidepanel；新增目标接口直接改 fetch。

## 2. Photoshop 插件：资产库双向同步（`tools/photoshop-asset-connector/`）

- 功能（UXP 面板）：
  - **资产 → PS**：浏览素材库，图片置入当前文档；
  - **PS → 资产库**：当前文档导出 PNG 存入指定分组；
  - **实时同步**：连后端 WebSocket，素材库变化自动刷新。
- 使用：启动后端 → PS 打开"大雄资产库"面板 → 填 `IP:端口` → 连接。
- 后端接口：素材库读取（`/api/asset-library`）、文件读取、上传（`/api/asset-library/items` 系列）；WebSocket 复用 `/ws/stats` 的广播机制（`ConnectionManager` main.py:79，`save_asset_url_library` 等保存函数会 `broadcast=True` 推送，main.py:7513）。
- 类似 SDPPP 的局域网通讯模式，无额外配置。

## 3. 即梦 CLI（`CLI/windows|macos|linux/jimeng/` + `tools/jimeng_cli_*.ps1`）

- 作用：把即梦（豆包系）能力以本地 CLI 形式接入：生图、生视频、放大、多帧分镜、排队查询。
- 安装/登录：根目录 `安装即梦CLI.bat` / `登录即梦CLI.bat` 调 `tools/jimeng_cli_install.ps1` / `jimeng_cli_login.ps1`；登录后网页端填 API 时选"即梦CLI"协议验证即可。
- 后端集成（main.py:5325–6260）：
  - 可执行文件定位 `jimeng_cli_executable`（5332），Windows 下支持 WSL（`jimeng_use_wsl` 5328、路径换算 5460–5475）；
  - 子进程调用 `run_jimeng_cli`（5522），JSON 提取 `jimeng_extract_json`（5494）；
  - 扫码登录 `/api/jimeng/login/start`（12869，二维码从 CLI stdout 提取 `jimeng_login_qr_from_text` 5609）；
  - 排队：`JimengPendingError`（5652）+ 专用异常处理器（5695）返回可轮询载荷；
  - 生图 6049 / 生视频 6122（首尾帧、多帧转场、时长范围 5843）/ 放大 6098。

## 4. Codex CLI 与 Gemini CLI（`CLI/windows|macos|linux/openai|gemini/`）

- 作用：用本地安装的 `codex` / `gemini` 命令行作为文本/生图渠道（复用 ChatGPT/Gemini 账号额度）。
- 后端：
  - Codex：`run_codex_cli`（main.py:4410）、生图经 gpt_image_2_skill（4774–4946）、状态 `/api/codex/status`（12694）；
  - Gemini CLI：`run_gemini_cli`（5095）、状态 `/api/gemini-cli/status`（12763）；
  - 两者都支持把输出图片落盘到 output 并转成 URL（`codex_output_image_files` 4466）。
- 安装脚本在 `CLI/README.md` 有平台对照表。

## 6. 内嵌 Python 运行时（`python/`）

- Windows 整包自带 `python\python.exe`（启动脚本优先使用）；`site-packages` 内含 fastapi、uvicorn、httpx、requests、Pillow、pydantic 等核心依赖。
- 无网盘会员的用户用 `python.zip` 解压恢复该目录。
- 升级依赖注意：离线安装脚本 `安装依赖.bat` 优先读本地 `packages/`（若存在）。

## 7. 系统内置静态配置（`static/runninghub/api_providers.json`）

- 随版本分发的 RunningHub 官方工作流/模型目录（含缩略图 `static/images/RunningHub-*.png`）。
- 加载时与用户配置合并（main.py:1111–1145）：系统条目提供"默认展示"，用户可隐藏/覆盖（`preserve_runninghub_hidden_overrides` main.py:1145）。
- **改它会影响所有用户默认视图**；用户侧修改保存在 `data/api_providers.json`。

## 8. 更新日志与版本

- `VERSION`：纯文本版本号（当前 2026.07.28.1）。
- `static/update-notes.json`：`{version, updated_at, items:[{type:'feature', text}]}`，首页展示；自更新成功后由更新流程刷新（`safe_update_notes` main.py:1475）。

## 9. macOS 支持

- `mac-启动服务.command`：启动服务；`mac-修复权限.command`：修复文件权限；`MAC-使用说明.md`：说明（含 opencode 兜底方案）。
- 后端代码跨平台（路径用 os.path），即梦 CLI 有原生 mac 安装脚本；WSL 仅 Windows。

## 10. 已知约束与坑（改动前必读）

1. **单文件后端**：main.py 无包结构，改动后需重启；函数间通过全局变量（如 `COMFYUI_INSTANCES`、`NEXT_TASK_ID`）耦合，改名要全局搜。
2. **节点 ID 注入**：ComfyUI 内置工作流的提示词/种子注入按节点 id 硬编码（main.py:18113 起），改工作流结构别动这些节点 id，或改走 WorkflowConfig 配置化。
3. **画布 JSON 全量保存**：前端每次保存 PUT 整个画布，节点对象过大时会变慢——新功能避免往节点里塞大块数据（如 base64 图）。
4. **公网 URL 要求**：APIMart 视频/数字人等上游要求公网可访问的图片/视频 URL，本地文件必须先走上传换链（main.py:8760 起、temp.sh/litterbox 9170 起），离线环境会失败。
5. **Key 安全**：任何新接口返回 provider 时必须走 `public_provider`（main.py:1313）脱敏。
6. **缩略图缓存**：`data/media_previews` 以内容 SHA 命名，删除/覆盖源图后旧缓存不会自动失效（清理入口 main.py:6643）。
