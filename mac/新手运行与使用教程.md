# 创客训练营｜无限画布 2026.08 内部版

## 新手运行与使用教程

这是一份给学员使用的简化说明。当前版本已经提前整理好常用配置，不需要一次性配置所有平台。建议先启动程序，使用已有的 VIP-GPT Key 生成第一张图片，再按需要配置 T8、RunningHub 或 AutoDL。

## 一、启动程序

### Windows

1. 完整解压整个文件夹，不要只解压其中几个文件。
2. 双击 `启动服务.bat`。
3. 等待浏览器自动打开网页。如果没有自动打开，请访问：

```text
http://127.0.0.1:3000/
```

4. 启动后不要关闭黑色命令行窗口。关闭它会停止程序。

### macOS

macOS 用户可以先尝试运行文件夹中的 `mac-启动服务.command`。如果系统阻止运行，右键文件并选择“打开”；仍然无法运行时，再使用 `mac-修复权限.command`。

如果你使用的是 Windows 网盘整包，一般不需要额外安装 Python 或运行依赖安装脚本。

## 二、第一次使用先看配置教程

请打开当前文件夹，查看：

```text
无限画布配置步骤（2026.10.02）.pdf
```

API 设置页面顶部也有“获取 api 的教程”入口，点击即可打开 PDF。

## 三、直接使用已有的 VIP-GPT Key

本内部版已经预先配置 VIP-GPT API Key，学员可以直接使用，不需要重新填写 Key。

操作步骤：

1. 打开“无限画布”或“智能画布”。
2. 新建生图节点，或打开已有的生图节点。
3. 在平台/提供商中选择 `VIP-GPT`。
4. 选择图像模型。
5. 输入提示词，点击生成。

这枚 VIP-GPT Key 预计可以生成约 200 张 1K 分辨率图片。实际可生成数量会受到平台计费、模型价格和账户状态影响，因此建议优先使用 1K 分辨率，不要随意选择高价或高分辨率模型。

请注意：

- 不要删除 VIP-GPT 平台。
- 不要修改或复制 API Key。
- 不要把 Key 发到公开群聊、网盘或社交平台。
- 如果出现额度不足或 Key 失效，请联系课程提供者。

## 四、前 3 个主要 API 入口

本版本重点配备左侧列表最上面的 3 个入口：

### 1. T8 API

T8 适合使用 Seedance 相关图像模型。

使用方法：

1. 点击 T8 API。
2. 点击“获取 Key”，注册并获取自己的 API Key。
3. 将 Key 粘贴到输入框并保存。
4. 系统会自动配置以下两个模型，无需手动拉取：

```text
G2 Image Lowprice
G2.5 Image Lowprice
```

如果保存后模型没有显示，刷新页面并重新保存一次 Key。

### 2. RunningHub

RunningHub 适合使用云端工作流、图像生成、视频生成和其他 AI 应用。

使用方法：

1. 点击 RunningHub。
2. 点击“获取 Key”注册并申请自己的 Key。
3. 将 Key 粘贴到项目中并保存。
4. 使用工作流时，确认工作流已经发布，并且必填图片和参数都已填写。

RunningHub 的工作流可能消耗积分或余额，具体以 RunningHub 平台显示为准。

### 3. AutoDL

AutoDL 是 GPU 云平台入口，主要用于租用 GPU、部署模型和运行 AI 环境。它不是普通的 OpenAI 生图 API。

需要使用 GPU 或部署模型时，点击 AutoDL 的获取入口，自行注册和配置。

## 五、无限画布的基本用法

普通无限画布适合使用节点连接完成复杂流程。

常用操作：

- 新建图片节点：上传或放入参考图。
- 新建提示词节点：输入描述文字。
- 新建生图节点：选择 VIP-GPT、T8 或其他已配置平台。
- 用连线把图片、提示词和生成节点连接起来。
- 点击生成节点上的运行按钮。
- 在输出节点中查看和下载结果。

画布操作：

- 拖动画布空白处：移动视野。
- 滚轮：缩放画布。
- 节点之间拖线：建立输入关系。
- 双击图片：预览或继续编辑。
- 右键节点：查看快捷操作。

## 六、智能画布的基本用法

智能画布更适合新手，不需要手动连接很多节点。

1. 新建一个智能画布。
2. 拖入图片或添加提示词。
3. 选择 VIP-GPT、T8 或其他可用平台。
4. 输入提示词。
5. 点击运行。

如果需要批量生成，可以使用循环功能，设置生成次数和不同的提示词变化。

## 七、提示词标准文件

文件夹中的 `gpt生图skill` 是图片生成提示词的标准文件，用于帮助生成更完整、更稳定的图片提示词。

使用图片生成时，可以参考其中的规则组织提示词。这个文件夹不需要移动、删除或修改。

## 八、常见问题

### 1. 页面打不开

确认黑色命令行窗口仍然打开，然后访问：

```text
http://127.0.0.1:3000/
```

### 2. VIP-GPT 生成失败

检查以下内容：

- 平台是否选择了 VIP-GPT。
- 是否选择了图像模型。
- 分辨率是否为 1K。
- 是否一次提交了太多任务。
- Key 是否已经失效或额度不足。

### 3. T8 没有模型

保存 T8 Key 后，系统会自动配置 G2 和 G2.5 Lowprice 模型。若没有显示，刷新网页后重新保存 Key。

### 4. RunningHub 工作流报错

确认 RunningHub Key 有效、工作流已发布、必填参数已经填写，并检查账户积分或余额是否足够。

### 5. 生成结果在哪里

图片通常会显示在输出节点中，同时保存在项目的 `assets\output` 文件夹里。

### 6. 如何查看更完整的配置方法

打开当前文件夹中的：

```text
无限画布配置步骤（2026.10.02）.pdf
```

也可以点击 API 设置页面顶部的“获取 api 的教程”。

## 九、推荐使用顺序

1. 双击 `启动服务.bat`。
2. 打开智能画布。
3. 选择 VIP-GPT。
4. 使用 1K 分辨率生成图片。
5. 需要 Seedance 模型时，再注册 T8 API。
6. 需要云端工作流时，再注册 RunningHub。
7. 需要 GPU 或部署模型时，再使用 AutoDL。

先成功生成第一张图片，再逐步学习其他功能即可。
