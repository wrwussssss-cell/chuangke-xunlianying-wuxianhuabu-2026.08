# 无限画布 Mac 外部版

这是面向 Apple Silicon（M 系列）Mac 的独立发布包。

## 启动

1. 首次运行双击 `mac-修复权限.command`。
2. 双击 `mac-启动服务.command`。
3. 用浏览器打开终端显示的本地地址。
4. 首次使用注册账号，之后用用户名和密码登录。
5. 进入“API 设置”填写自己的 Key。

配置教程位于本目录的《无限画布配置步骤（2026.10.02）》文件。

本目录不包含真实 API Key、个人画布、历史记录和生成素材。Intel Mac 兼容性待确认。

完整更新记录请查看仓库根目录的 [`CHANGELOG.md`](../CHANGELOG.md)。
